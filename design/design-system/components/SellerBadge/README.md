Shows a seller's rank (Hatchling, Scale, Fang, Basilisk, Dragon) as a line icon plus its name, and the Founding Seller badge beside it when earned.

- Icons are 16 px in chips, 24 px in lists, 48 px on the ranks page. Line art, 2 px stroke at 16 px, `currentColor`.
- Only Dragon uses `rune` and the `rune-soft` fill, so it stays rare. Every other rank is `ink` on `paper`.
- On the ranks page, add 1 to 5 pips so the level reads without the icon.
- Place it right after the seller name, never inside the price column.
- Fees and requirements per rank are set by the CEO; perks text comes from the copywriter.
