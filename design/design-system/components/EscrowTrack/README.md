The order timeline shown on every order page: Paid → Delivered (with proof) → Buyer confirms → Released.

- Completed steps use `released`; the current step pulses in `held` with a `held-soft` halo; future steps use `rule`.
- Delivered always links to the seller's photo or video proof.
- Bullizard has no auto-release. If the buyer doesn't confirm, staff review the proof, never before 24 hours, and there is no countdown. If it is still not released, the seller sends a follow-up to support.
- If a dispute opens, the track freezes and the current dot switches to `disputed`.
- On phones (under 520px) the four steps stack vertically.
