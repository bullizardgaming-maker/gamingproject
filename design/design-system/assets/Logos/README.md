# Logos

- `bullizard-mark.svg`: the main mark, the coin-eye (horns, coin ring, slit pupil). Ink #16202e.
- `bullizard-mark-light.svg`: the same in #eef1f5 for dark backgrounds.
- `bullizard-mark-solid.svg`: solid coin version for 16–20 px and favicons.
- `bullizard-logo.svg`: the name "Bullizard", B with horns and a fang, ink. Outlined from Alexandria 800.
- `bullizard-logo-light.svg`: the name in #eef1f5 for dark backgrounds.
- `bullizard-app-icon.svg`: dark coin-eye on the green accent (#4bae24), 28 px corner at 128 px.

One colour per lockup, never two-tone.
